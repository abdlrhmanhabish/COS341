Example programs for the naming rules (phase 2a) and the type rules (phase 2b):
valid_*   are correct programs. The compiler writes tree.xml and symbol-table.txt and ends with exit code 0.
naming_*  break a naming rule. The compiler reports a naming error and ends with exit code 3.
type_*    break a type rule. The compiler reports a type error and ends with exit code 4.
